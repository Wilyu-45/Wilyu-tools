# Cupsensor

晃动播放视频应用 - 通过摇晃设备来控制视频播放。

## 功能

- 晃动设备即可播放/暂停视频
- 简单的视频选择界面
- 粉色杯子图标设计

## 技术栈

- Kotlin
- Android SDK
- Gradle

## 构建

```bash
./gradlew assembleDebug
./gradlew assembleRelease
```
